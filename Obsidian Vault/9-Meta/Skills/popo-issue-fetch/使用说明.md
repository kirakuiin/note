# Popo 工单 Skill 使用说明

可以使用 `$popo-issue-fetch` 拉取 popo 上派给自己的工单，看内容和截图，并接着定位、修复问题。

Skill SVN 地址：

```text
svn://svn-xyq.gz.netease.com/svn/products/xy1/develop/client/common/ai/.agents/skills/popo-issue-fetch
```

第一次使用前，在 skill 目录执行一次（需要 Python 3.11 以上）：

```powershell
python -m pip install -r requirements.txt
```

## 主要能力

- 列出派给自己的工单，默认只看还没处理完的。
- 列出自己参与的制作内容，以及每个里面还剩多少单。
- 读工单的完整内容：问题描述、补充说明、重现步骤、状态流转、客户端日志。
- 自动下载工单截图并看图，不用只靠标题猜。
- 用策划单号找到对应的制作内容，再看自己在里面的单。
- 读懂之后直接接着定位代码、动手修。
- 只读工单，不会改状态、回复或重新指派。

## 怎么提需求

直接用大白话说，不用报自己的名字，也不用给任务 ID。

看自己还有哪些单没处理：

```text
$popo-issue-fetch 我现在还有哪些没处理的工单？按任务分下类
```

看某个单说的是什么：

```text
$popo-issue-fetch 291418 这个单说的是什么问题？图里是什么情况
```

从策划单找自己的单：

```text
$popo-issue-fetch #643675 登录相关dprf log接入 这个制作单下，有哪些单是派给我的
```

看某个制作内容里派给自己的单：

```text
$popo-issue-fetch 全屏战斗界面这个任务下派给我的单，都列出来
```

读完直接让它动手：

```text
$popo-issue-fetch 291418 这个单帮我定位下代码在哪改，mhimage_trunk 分支
```

一次过一批，排个处理顺序：

```text
$popo-issue-fetch 把全屏战斗任务下派给我的单都读一遍，按优先级和改动大小给我排个顺序
```

看同事的单：

```text
$popo-issue-fetch 王卓为手上还有哪些待处理的单
```

## 注意事项

默认只看待处理的单。要翻已经关闭的老单子或已收尾的制作内容，话里要说明「包括已关闭的」。

默认按当前电脑的登录账号判断「我」是谁。共用机器或账号对不上时，直接说清楚查谁的单；每次查询都会显示用的是哪个账号，可以核对。

工单内容是项目内部资料，可能含玩家 ID、日志和未发布功能，只在本地看，不要外发。

单子的流转和回复还是自己在 popo 上操作。如果描述不足以定位问题，可以让它列出缺什么，再去找提单人补。
