# 梦幻西游黑话词典查询器

本 skill 用于把策划案、聊天记录、提单、用例中的**玩家黑话/缩写**翻译成正式名称或配置含义，避免误读需求。

```
mh-slang-dict/
├── SKILL.md                      # 查询流程与章节索引
├── scripts/lookup_slang.py       # 查表脚本（优先使用）
└── references/slang-dict.md      # 词典全文（章节用中文序号标记，供脚本解析）
```

## 查询流程

1. 优先执行 `scripts/lookup_slang.py`（命中即用，**不要**联网或调用梦幻精灵）。
2. 脚本未命中时，用 grep 兜底（见下）。
3. 命中多义项时（如 `WDD`、`CA`、`JY`），按上下文选，并在回答中标注歧义。
   战斗操作按第十一章的门派解释；完整句子含人名时，提取“拉我”“起球”等词条查询。脚本精确查表，不会自动替换人名。
4. 全部章节都查不到时，才回退线上词典/精灵，并**提示用户词典需更新**。

## 查询命令

```bash
# 查一个或多个黑话
python scripts/lookup_slang.py DT 66 WJ 大金 "#4"

# 列出全部章节及词条数
python scripts/lookup_slang.py --chapters

# 列出某章全部词条（支持 四 / 4 / 一之二 / 全名）
python scripts/lookup_slang.py --chapter 四

# 战斗操作：整章、同词不同门派
python -B scripts/lookup_slang.py --chapter 11
python -B scripts/lookup_slang.py "拉我" "起球" "奇袭野兽特技"

# grep 兜底（脚本未命中时）
Select-String -Path references/slang-dict.md -Pattern "\|\s*(DT|66|WJ)\s*\|"
```

**脚本输出约定**：每条命中打印 `[章节] 黑话 -> 解释`；未命中打印 `[未命中] xxx` 且退出码为 1。
未命中时不要直接编造解释。

**特例**：

- `#n`（如 `#4`、`#99`）直接识别为表情快捷键，原样保留。
- 造型编号支持省略前导 0（`212` → `0212` 孙小圣）。
- 复合写法（`晶清/JQ`、`WJB / 无级别`）会自动拆分逐个查。

## 使用注意

- **多义优先按上下文**：`WDD` = 门派无底洞 / 副本无底洞；`CA` 在配置表语境多为 CA 表格，仅坐标语境才是长安城；`JY` = 建邺城 / 简易。
- **`#n` 表情**：用例中直接保留原文，不需要翻译。
- **定位为查表工具**：只做术语翻译，不代替玩法代码导航（需要代码位置时用对应玩法 skill，如 `gameplay-navigators`、`school-guide`）。
- **战斗操作歧义**：同一句“拉我”“点灯”“秒”按门派解释；药品简称结合具体物品确认。奇袭单独解释，不作为普通技能的前置条件。

## 维护 / 更新词典

词典来源：KM《梦幻西游黑话词典》 https://km.netease.com/wiki/826/page/474652

更新步骤：

1. 拉取该 KM 页面最新内容。
2. 只保留「一、」之后的 AI 可读正文；页面上的【人工阅读，AI不读】提示不要带进来。
3. **章节标题必须保留中文序号格式**（`一、门派缩写`、`一之二、门派编号`、`十、角色造型编号`），新增章节同样用 `一、`/`一之二、`/`十、` 划分——脚本依赖该格式转换。
4. 更新 `references/slang-dict.md` 的 KM 来源章节，保持表头列数一致；保留独立维护的第十一章，不要用 KM 正文整文件覆盖它。
5. 若新增章节，同步补进本文档「章节索引」表。

第十一章按实际技能与物品配置维护；更新时核对名称和ID，保留门派歧义，避免把特定场景的操作顺序当作技能通用前置条件。
