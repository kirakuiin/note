# Baseline (without ingest skill) — Eval 1

Without the ingest skill, the agent would:
- Not know the standard session file structure (背景/关键讨论/结论/产出物/后续)
- Not know to ask public vs private first
- Not know the file naming convention (1-Sessions/YYYY/MM/YYYY-MM-DD-topic.md)
- Not know to check TAGS.md for valid tags
- Not know to propose wiki updates after session creation
- Not know to update _log.md

The agent would likely just create a generic markdown note without proper frontmatter or structure.
